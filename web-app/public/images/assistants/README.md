# Starter assistant icons

`emerald.png`, `book.png`, `book-and-quill.png` and `compass.png` are original pixel art in the style of the game's items, generated by `scripts/assets/starter-icons.py` from 16x16 grids hand-authored in that script (run it with Python and Pillow to regenerate them); they are not the game's textures and are covered by the same licence as the rest of this repository. `blaze.png`, `coal.png`, `quartz.png` and `redstone.png` are older icons that were added with the specialized assistants (#47) and are not generated by that script. Keep every PNG here at 30 KB or less; `web-app/src/__tests__/assistantIconSize.test.ts` enforces it.
