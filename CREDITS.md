# Credits

Flint is a fork of [Jan](https://github.com/janhq/jan) and keeps porting fixes and features from Jan
and from [Atomic Chat](https://github.com/AtomicBot-ai/Atomic-Chat), another Jan fork. The people below
wrote the upstream changes Flint ported or adapted, or reported the upstream issues Flint fixed.
Thank you.

Everyone who contributed to Jan before the fork is credited by the Jan history that Flint keeps.
This file covers work picked up from upstream after the fork. Ports often differ from the original
(adapted to Flint's code, extended or only partly taken), so any bug in a port is Flint's, not theirs.

When a port lands, its commit credits the upstream author (as the commit author, or with a
`Co-authored-by` trailer) and the pull request names the upstream PR. New ports add a line here.
